# Reference verdicts of the RVWMO calibration suite

The 36 tests of this directory are the `test/axiomatic/*.toml` tests of Isla (commit `7f6882b`), which Isla
derives from the RISC-V litmus tests of the litmus-tests-riscv project (generated by `diy7`). The expected
verdict of each test is the herd reference result that Isla ships with them (`test/axiomatic/refs`, copied here as `refs_herd.txt`):
"allowed" when herd reports the final condition as reachable, "forbidden" when it reports it as never reachable.

Measured with the model of `model/REBUILD.md` and the RVWMO Cat model of Isla:

```
cd $ISLA_ROOT
./target/release/isla-axiomatic -A $ISLA_IR -C configs/riscv64_g2.toml \
  --footprint-config configs/riscv64_g2.toml -m web/client/dist/riscv.cat -s 600 -T 2 <test>.toml
```

35 of 36 agree. The one disagreement, `MP+fence.rw.rw+addr`, writes its address dependency with the idiom
`xor xN,xN,xN`, which the architecture treats as a dependency and Isla folds to a constant (Section 8.2 of the paper).

The comparison is done by `compare_refs.sh` (in this directory), which reads `refs_herd.txt` and a results file
with one verbatim Isla summary line per test. Run on the recorded results (`measured_isla.txt`, copied from
`litmus/frozen-suite/RESULTS.md`, Section 3.2) or on a fresh run of `litmus/frozen-suite/run_baseline_all.sh`:

```
bash litmus/rvwmo-suite/compare_refs.sh                                  # recorded results
bash litmus/rvwmo-suite/compare_refs.sh "$OUT_DIR/baseline_rvwmo.txt"    # a fresh run
```

It prints one line per test and the number of agreements; the recorded results give `35 of 36 agree`.

The `expect = "sat"` field inside each `.toml` is the satisfiability query Isla poses for the final condition,
not the reference verdict; the reference verdicts are the column above.
